# API Contract: GET /contributions

Search contributions by title or owner. Results are sorted and paginated.
Machine-readable schema: `/openapi.json` (generated by FastAPI).

## Request

| Parameter  | Type    | Default | Valid       |
| ---------- | ------- | ------- | ----------- |
| `q`        | string  | none    | any string  |
| `page`     | integer | `1`     | 1–1,000,000 |
| `pageSize` | integer | `10`    | 1–100       |

All parameters are optional.

### Rules

**`q`**: literal, case-insensitive substring match on `title` or `owner`.

- Case is folded the Unicode way (`casefold`), so `ÉCOLE` matches `École`. Accents are not
  removed: `jose` does not match `José`.
- Special characters (`.`, `*`, `[`, `?`, …) are plain text, never a pattern.
- Empty or whitespace-only means no filter. Any other value is used as sent, not trimmed.
- In a query string, `+` decodes to a space. Send `%2B` for a literal plus.

**`page` / `pageSize`**: must be whole numbers in range, otherwise 422. Text that is not a number
(`abc`, empty) is 422. How other number-like text is read (`+1`, `1.0`) is FastAPI's default parsing.

**FastAPI defaults (not changed):** parameter names are case-sensitive, and the last value of a
repeated parameter is used (`?page=1&page=2` is page 2). Unknown parameters are ignored, so a
misspelt `?pagesize=50` gives the default page size of 10.

## Behaviour

1. Filter by `q`.
2. Sort by `startTime` ascending, then `id` ascending (stable, deterministic order).
3. `total` = number of matches, counted before pagination.
4. Return items `(page − 1) * pageSize` to `page * pageSize`.

A page past the end (but within the maximum) is valid: 200, empty `items`, `total` unchanged.

**Known limitation:** offset pagination can skip or repeat items if contributions
are added or removed between page requests.

## Response: 200

```json
{
  "items": [
    {
      "id": 3,
      "title": "API design review",
      "owner": "Sarah Lee",
      "startTime": "2024-01-10T10:30:00Z"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 10
}
```

| Field      | Type    | Notes                                   |
| ---------- | ------- | --------------------------------------- |
| `items`    | array   | This page, in sorted order              |
| `total`    | integer | All matches, before pagination          |
| `page`     | integer | Echoes the request                      |
| `pageSize` | integer | Echoes the request (not `items.length`) |

**Item:** `id` integer (unique) · `title` string · `owner` string · `startTime` string

All four fields are always present and never `null`. `title` and `owner` may be `""`.
`startTime` is always sent in UTC with a `Z` suffix (`2024-01-10T10:30:00Z`). A stored time with
another offset is converted to UTC before it is sent.

## Errors

| Status | When                                                                                |
| ------ | ----------------------------------------------------------------------------------- |
| 422    | `page` < 1 or > 1,000,000, `pageSize` < 1 or > 100, or either is not a whole number |

```json
{
  "detail": [
    {
      "type": "less_than_equal",
      "loc": ["query", "pageSize"],
      "msg": "Input should be less than or equal to 100",
      "input": "200"
    }
  ]
}
```

## Examples

| Request                                        | Result                                                   |
| ---------------------------------------------- | -------------------------------------------------------- |
| `GET /contributions`                           | 200, first 10 in sorted order                            |
| `GET /contributions?q=sarah&page=2&pageSize=6` | 200, matches 7–12 for "sarah"                            |
| `GET /contributions?page=999`                  | 200, `items: []`, `total` unchanged                      |
| `GET /contributions?q=%20api`                  | 200, matches " api" with the leading space (not trimmed) |
| `GET /contributions?pageSize=200`              | 422, body as above                                       |
| `GET /contributions?page=1000001`              | 422, `page` above the maximum                            |
| `GET /contributions?page=99999999999999999999` | 422, never a 500                                         |
| `GET /contributions?pagesize=50`               | 200, `pagesize` is ignored, so 10 items (default size)   |
